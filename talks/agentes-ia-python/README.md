# Agentes de IA com Python

Minicurso apresentado no IFTech.

## Objetivos

Introduzir os conceitos de:

- IA Generativa
- LLMs
- Agentes de IA
- Engenharia de Prompt
- Integração com APIs
- Automação com Google Forms e Google Sheets

## Tecnologias

- Python
- Google Colab
- Groq
- Google Forms
- Google Sheets

## Conteúdo

### Parte 1
- O que é IA Generativa
- O que é um LLM
- O que é um Agente de IA

### Parte 2
- Configurando a API da Groq
- Primeiros prompts

### Parte 3
- Gerador de Emails
- Análise de Sentimentos
- Extração de Dados

### Parte 4
- Projeto Final
- Agente de Classificação de Chamados
